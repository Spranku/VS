## 🎮 Gameplay

Fight alongside your friends in this co-op FPS. The vertical shooter design adds a unique twist to traditional shooter mechanics. Key features include:

- 🤝 **Co-op multiplayer** — team up with friends
- 🎮 **Steam integration** — lobby system, achievements, and more
- 🔫 **First-person combat** with vertical level design
- 🧠 **AI enemies** with dynamic behavior
- 🎯 **Weapon system** with multiple firearms

---

## 🛠️ Tech Stack

- **Engine:** Unreal Engine 4
- **Language:** C++, Blueprints
- **Platform:** Windows PC
- **Network:** Steamworks SDK (co-op multiplayer)
- **Version Control:** Git LFS
